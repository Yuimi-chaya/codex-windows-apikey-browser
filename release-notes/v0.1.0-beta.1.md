# v0.1.0-beta.1 (prerelease)

## 中文

首次提供独立的 Windows 图形界面 EXE。可查看当前用户注册的 Codex App 版本与安装路径、选中的 Codex 数据目录、CUA 运行时版本、实际补丁文件和恢复资料；支持自动发现、手动选择数据目录、解锁与还原。GUI 复用原有的指纹校验、进程检查和恢复机制，不修改 Codex 安装包。

仅支持文件指纹完全匹配的 Windows CUA 0.0.11 / 0.0.24。未知版本或其他工具改动的服务不会被覆盖。操作前须完整退出 Codex 与 Codex++，不可与 Codex++ 原生浏览器适配同时使用。界面“已解锁”只代表磁盘状态，首次使用仍需在重新打开的 Codex 中实际测试浏览器。还原不能清除浏览器扩展自身保留的请求标识。

这是未签名的测试版。源码和临时副本的自动化测试已通过；独立 EXE 尚待不同机器上的真人验收。请从本发布页下载并核对发布资产的 SHA-256。

## English

First standalone Windows GUI EXE. It displays the current user's registered Codex App version and installation path, the selected Codex data directory, CUA version, actual service target, and recovery location. It discovers the plugin descriptor automatically, lets you select a different `.codex` data directory, and supports apply/restore through the existing fingerprint, process, and recovery guards. It does not modify the Codex app package.

Only exact Windows CUA 0.0.11 / 0.0.24 fingerprints are supported. Unknown builds or files modified by another tool are not overwritten. Fully exit Codex and Codex++ before applying/restoring; do not combine this tool with the Codex++ native browser adapter. "Unlocked" describes the on-disk state, not a successful browser connection. Restoring the service cannot erase identification retained inside the browser extension.

This unsigned prerelease has automated source/temporary-copy coverage, but the standalone EXE still needs human acceptance on another machine. Download it from this release and verify the published asset's SHA-256.
