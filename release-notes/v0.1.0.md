# v0.1.0

## 中文

Windows 浏览器兼容工具现可统一识别并处理本工具或 Codex++ 留下的恢复状态。界面会显示当前恢复资料的归属，以及服务文件是原件、已解锁、开关关闭、运行中还是存在冲突；“解锁浏览器”和“恢复原件”会在执行前重新核验。

与 `v0.1.0-beta.1` 不同，本版可在确认 Codex++ 的 journal、原件、候选文件、监控回执和锁均有效后，使用其恢复资料完成解锁与还原。独立补丁尚在活动时会优先提供对应的还原入口；未知文件、未完成的监控状态或双重活动补丁不会被覆盖。运行中的 Codex/Codex++/CUA 会阻止写入，而不是被误报为不支持的运行时。

此版的统一恢复与解锁已由用户在另一台 Windows 电脑上真人测试通过。仅支持文件指纹匹配的 Windows CUA 0.0.11 和 0.0.24；这不代表所有浏览器、扩展、站点或未来 Codex 版本都已验证。磁盘“已解锁”状态也不等于浏览器连接成功。

操作前请完整退出 Codex App、Codex++ launcher 和 manager，并保持退出直到操作完成。Codex++ 在 launcher 启动时读取内建兼容选项；若以后仍通过 Codex++ 启动，应保持该选项开启，否则下次启动会还原服务。本工具不会修改该设置，也不会清除扩展内部保留的请求标识。EXE 未使用受信任的代码签名；请从本发布页下载并核对 SHA-256。本工具并非 OpenAI 官方产品。

## English

The Windows browser compatibility tool now recognizes recovery state created by either this tool or Codex++. The GUI shows the recovery owner and whether the service is original, unlocked on disk, disabled, in use, or conflicting. Unlock and restore actions recheck the state before writing.

Unlike `v0.1.0-beta.1`, this release can use Codex++ recovery material after verifying its journal, original and candidate files, monitor receipt, and locks. An active standalone patch retains its own restoration path. Unknown files, unfinished monitor state, and simultaneous active adapters are not overwritten. Running Codex/Codex++/CUA processes block writes instead of being misreported as an unsupported runtime.

The unified unlock/restore flow passed user testing on another Windows machine. Support remains limited to the exact Windows CUA 0.0.11 and 0.0.24 file fingerprints; this is not a claim of coverage for every browser, extension, site, or future Codex version. An "unlocked" disk status does not prove browser connectivity.

Fully quit Codex App and the Codex++ launcher and manager before operating, and keep them closed until completion. Codex++ reads its built-in compatibility setting when its launcher starts. If you continue launching through Codex++, keep that option enabled; otherwise its next start restores the service. This tool neither changes that setting nor clears identification retained by a browser extension. The EXE has no publicly trusted code signature; download it from this release and verify its SHA-256. This is not an official OpenAI product.
